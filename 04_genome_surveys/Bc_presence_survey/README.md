Scripts and results for the targeted survey testing whether the six principal contracted
gene families of *Pheropsophus javanus* (cuticle proteins, steroid-associated
sulfotransferase, cytochrome P450) retain homologs in the *Brachinus crepitans* gland and
combined-tissue transcriptomes (Vogel et al., 2025). Supports the "phylogenetic inertia"
alternative test and Supplementary Table S36, Part D of the manuscript (INZ-2026-07-520).

## Conclusion (category I for all six families)

*Brachinus crepitans* retains homologous transcripts for 25 of the 27 *P. javanus* query
proteins (the two non-hit members are short partial gene models, 63/145 aa — likely
annotation fragments). All contractions are therefore specific to the *P. javanus* lineage
rather than inherited from the brachinine common ancestor. See `results/family_summary.csv`.

Note: family OG0000273 (the KEGG ko00140 "steroid hormone biosynthesis" driver) encodes
**sulfotransferases** (SULT; Pfam sulfotransferase domain; KEGG EC 2.8.2.4), not
cytochrome P450s. The BR:ko00199 "Cytochrome P450" enrichment signal is driven separately
by the bona fide CYP family OG0000272 (five PF00067-domain genes); three CYP families
occur in the family-level-BH-significant set (OG0000230, OG0000272, OG0000524). For CYP
families, orthogroup-level copy-number estimates are not applicable because the CYP
superfamily is fragmented across 46 *P. javanus* orthogroups.

## Pipeline (run in order)

| Step | Script | Description |
|---|---|---|
| 01 | `scripts/01_extract_and_prepare.py` | Extract Bc contigs from the two Vogel et al. (2025) Supplemental xlsx files (gland part-assembly 30,565 contigs; combined-tissue assembly 50,332 contigs) and assemble the 27 PJA query proteins (six contracted families). Output: `data/Bc_glands.fna`, `data/Bc_combined.fna`, `data/pja_27_queries.faa`. |
| 02 | `scripts/02_run_blast.sh` | Concatenate assemblies, build BLAST DBs, run tBLASTn (27 queries vs Bc contigs, BLAST+ v2.12.0, E-value ≤ 1×10⁻⁵) and BLASTx (best-hit contigs vs PJA proteome) for the reciprocal-best-hit check. Output: `results/tblastn_pja_vs_Bc.tsv`, `results/blastx_Bc_vs_PJA.tsv`. |
| 03 | `scripts/03_classify.py` | Merge forward hits with reciprocal hits, estimate Bc copy numbers, assign categories I/II/III. Output: `results/partD_table.csv` (per-query table = Supplementary Table S36, Part D), `results/family_summary.csv`. |

## Inputs (not included; obtain as described)

- `Vogel_et_al_Supplemental-File-S1_Transcriptome-GLANDS_Annotation-TPM-NOIseq.xlsx` and
  `Vogel_et_al_Supplemental-File-S2_Transcriptome-COMBINED_Annotation-TPM-NOIseq.xlsx` —
  Vogel et al. (2025) supplementary files; contig sequences in the "Sequence Data" column.
- `PJA_PEP.fas` — *P. javanus* annotated proteome (27,510 proteins, headers `>PJA|<gene>`).
- BLAST+ (tested with v2.12.0); Python 3 with pandas, openpyxl.

Large derived files (`Bc_glands.fna` + `Bc_combined.fna`, ~80 MB) are regenerated by step 01
and therefore not stored here. `data/Bc_all.fna` and the BLAST DBs (`Bc_db.*`, `PJA_db.*`)
are regenerated by step 02.

## Classification categories (Pangdun's protocol)

- **Category I** — Bc has homologous transcripts → *P. javanus*-lineage-specific contraction
  (supports streamlining interpretation).
- **Category II** — Bc transcriptome also lacks homologs → loss predates the brachinine
  ancestor (transcriptome absence is weak evidence; not observed in this study).
- **Category III** — *P. javanus* gene model itself is a short partial model →
  assembly/annotation artefact (observed for Chr4.706 and Unplaced6.11 at the gene level;
  does not change the family-level category I conclusion).

## Output file formats

- `tblastn_pja_vs_Bc.tsv` — outfmt 6: `qseqid sseqid pident length qlen slen evalue bitscore`
  (qseqid format `<gene>|<orthogroup>`).
- `blastx_Bc_vs_PJA.tsv` — outfmt 6: `qseqid sseqid pident length evalue bitscore`.
- `partD_table.csv` — per-query best hits in gland (S1) and combined (S2) assemblies,
  identities, alignment lengths, and reciprocal-best-hit result.
- `family_summary.csv` — per-family copy numbers, identity ranges, Bc copy estimates and
  category assignment.
